# Feature: Task Metadata

Tasks in the application contain rich metadata to help users manage their workload.

## 1. Priority Levels
- **Levels**: Low, Medium, High.
- **Visuals**: Color-coded badges (Green for Low, Yellow for Medium, Pink for High).
- **Default**: New tasks are set to "Medium" by default.

## 2. Due Dates
- **Format**: Users can select a date using a native date picker.
- **Tracking**: 
  - **Overdue**: Highlighted in red if the due date has passed.
  - **Due Today**: Highlighted in orange if the task is due today.
- **Visuals**: Dedicated badges show the formatted date with a representative emoji (⚠️, ⏰, or 📅).

## 3. Notes
- **Storage**: Tasks can store additional notes, though currently primarily used for search matching.
