# To-Do App Feature Documentation

Welcome to the feature documentation for the To-Do Application. This project is built with React, TypeScript, and Vite, focusing on a premium user experience.

## Feature Index

### Core Task Management
- [Task Life Cycle](./features/task-life-cycle.md): Adding, Toggling, Editing, and Deleting tasks.
- [Task Metadata](./features/task-metadata.md): Priorities, Due Dates, and Status tracking.

### Organization & Productivity
- [Organization (Tagging)](./features/organization.md): Categorizing tasks with dynamic tags.
- [Search and Filtering](./features/search-and-filtering.md): Quickly finding and isolating tasks.
- [Sorting](./features/sorting.md): Ordering tasks by different criteria.
- [Statistics](./features/statistics.md): High-level overview of productivity metrics.

### System Infrastructure
- [Data Persistence](./features/data-persistence.md): How data is saved using LocalStorage.
